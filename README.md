# CADCraft web runtime mirror

Pinned, unmodified CADCraft v0.14.0 browser runtime, mirrored for CDN delivery. Contains no drawings, models, customer data or credentials.

Official source: https://github.com/storytold/cadcraft
Official release: https://github.com/storytold/cadcraft/releases/tag/v0.14.0

The WebAssembly is gzip-compressed losslessly. Its decompressed SHA256 is d6496349579ff0207d3b4c857186febbad6de7ef4ad83527b708595c3e618d9b.
The official release ZIP checksum was verified before extraction. JavaScript and snippets are unchanged.
